# Haven

KnotGate's peaceful sector: Wolfgate's Standard round without faction stations, the TSF/PDV standoff or hostile
events. The `KGHaven` game preset spawns the ordinary POIs, Caelestinus and the market, but not the TSF, PDV, USSP,
MMC, Underground, Zeta Node or Zvezda stations, so their faction jobs never open. `KGHavenEventScheduler` runs only
calm events (pest migrations, sentience, solar flares, bluespace cargo). The storyteller runs `KGEncounterPresetHaven`:
friendly traffic and freight, no threats, distress calls or patrols.

Most of the work is server configuration, not code. The KnotGate `server_config.toml` sets:

| Setting | Value | Why |
|---|---|---|
| `game.defaultpreset`, `game.fallbackpreset` | `KGHaven` | the preset above |
| `vote.preset_enabled` | `false` | no lobby vote back to a Wolfgate preset |
| `wg.encounters.preset` / `wg.encounters.vote` | `KGEncounterPresetHaven` / `false` | friendly traffic only |
| `wg.sector.enabled`, `wg.defcon.enabled`, `wg.judgeline.enabled` | `false` | no territory, threat level or law response |
| `wg.remade.sector.enabled`, `wg.remade.siege.enabled`, `wg.remade.signals.enabled`, `wg.remade.dread.sector`, `remade.garrison_enabled` | `false` | no Remade incursions |
| `wg.ship_squatters` | `false` | no NPCs moving into landed ships |
| `wg.lattice.tacet`, `wg.lattice.choir`, `wg.lattice.coda_rot` | `false` | no Lattice endgame hazards |
| `adminlogs.server_name` | `knotgate` | rounds and logs in the shared database say where they happened |

Left on deliberately: planets, caverns and expeditions (their fauna is opt-in danger a player travels to), and
companies (they're saved in character profiles shared with Wolfgate; see Docs/_KG/Upstream).

Still open: faction-locked vessels in the shipyard keep their faction job slots, and NF salvage expeditions keep
their mobs. Both need a switch in Wolfgate rather than edits here.
